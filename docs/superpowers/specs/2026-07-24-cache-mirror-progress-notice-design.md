# 缓存镜像下载提示优化设计

## 目标

内网缓存镜像确认命中后、下载进度条开始前，输出镜像来源：

```text
 - Use cache mirror http://192.168.x.x:8686
Downloading [========================================] 100.0% 43.50M/43.50M
```

## 实现

- 在 `internal/install/runner_download.go` 包装现有镜像下载进度回调。
- 镜像返回成功响应并准备创建进度条时，先向安装输出写入 ` - Use cache mirror <URL>`。
- 删除下载完成后的 ` - Using cache mirror file ...`，避免重复提示。
- 镜像未命中、请求失败、回退源站或静默模式时，不显示该提示。
- 不修改缓存键、下载、回退、校验或镜像服务协议。

## 验证

- 回归测试断言提示位于下载进度输出之前。
- 回归测试断言成功下载后不再输出旧提示。
- 运行 `go test ./...`。
